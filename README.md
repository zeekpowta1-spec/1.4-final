# MyFirstMillion 1.6

Android app **«Мій перший мільйон»** — простий трекер великих фінансових цілей.

## Що нового в 1.6

- Темна тема за замовчуванням, світла тема доступна вручну.
- Власна назва фінансової цілі: мільйон, автомобіль, подорож, резерв або будь-яка інша мрія.
- Швидкі пресети назв цілей.
- Вершини накопичень і наступна найближча вершина.
- Калькулятор «Що буде за цей термін».
- Симулятор додаткового щомісячного внеску.
- Розрахунок у режимах день/місяць та рік/місяць з базою 30 днів у місяці.
- Автопрокрутка до активного поля під час введення.
- Преміальна зелено-золота візуальна система та власна іконка застосунку.
- Історія внесків не втрачається при обнуленні поточної шкали.

## GitHub Actions

У репозиторії вже є `.github/workflows/android-build.yml`.

Workflow:
- перевіряє Gradle-проєкт;
- збирає debug APK;
- збирає release AAB;
- додає APK та AAB як Artifacts.

Використовуються JDK 17 та Gradle 8.13.
